# Senior Full-Stack & AI Solutions Engineer

**Company:** Apex Financial Intelligence  
**Location:** Remote / Hybrid (EST Timezone)  
**Employment Type:** Full-Time  
**Experience Level:** Senior (6–9+ years)  
**Industry:** FinTech / Applied AI & Machine Learning  

---

## 🏢 About the Role

Apex Financial Intelligence builds intelligent accounting and financial categorization platforms powered by generative AI and modern cloud microservices. We are looking for a **Senior Full-Stack & AI Solutions Engineer** who can bridge the gap between high-performance .NET backend services, intuitive modern web frontends (React / Next.js), and cutting-edge applied AI/LLM systems.

---

## 🎯 Key Responsibilities

- **Applied AI & LLM Systems:** Architect and deploy intelligent classification engines, RAG (Retrieval-Augmented Generation) pipelines, and prompt orchestration workflows.
- **Cost & Latency Optimization:** Implement multi-tiered classification and confidence scoring logic to optimize LLM token consumption and reduce API latency.
- **Backend API Engineering:** Build high-throughput, low-latency REST APIs in C# / ASP.NET Core and Python.
- **Frontend Development:** Develop responsive, accessible analytics dashboards and interactive data visualization interfaces in React, Next.js, and TypeScript.
- **Data Pipelines & Evaluation:** Prepare synthetic datasets, fine-tune lightweight transformer models (BERT, SetFit), and build automated evaluation harnesses (precision, recall, F1).
- **Mentorship & Quality:** Participate in sprint planning, conduct constructive code reviews, and guide junior engineers on AI and full-stack best practices.
