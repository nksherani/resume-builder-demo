# Principal Backend Engineer – Distributed Systems

**Company:** NexaScale Global Logistics  
**Location:** Remote (Global / North America overlap)  
**Employment Type:** Full-Time  
**Experience Level:** Principal / Staff (9–12+ years)  
**Industry:** Enterprise Logistics, Supply Chain & High-Volume Messaging  

---

## 🏢 About the Role

NexaScale is looking for a **Principal Backend Engineer** to design and scale our mission-critical real-time logistics, messaging, and workforce coordination engine. You will be responsible for scaling backend systems processing tens of millions of monthly transactions, optimizing database performance, and driving asynchronous event-driven architecture across multi-region cloud infrastructures.

---

## 🎯 Key Responsibilities

- **High-Throughput Distributed Architecture:** Architect and optimize distributed backend systems capable of processing **10M+ monthly transactions** with sub-100ms latencies.
- **Messaging & Event Streaming:** Design and implement resilient asynchronous messaging pipelines utilizing message brokers, queues, topics, and publish/subscribe patterns.
- **Database Scalability & Performance:** Lead database architecture, index tuning, query plan analysis, and data partitioning across SQL Server and NoSQL datastores.
- **Architectural Governance:** Author Architectural Decision Records (ADRs), define SLA/SLO metrics, and lead cross-squad architecture reviews.
- **Reliability & Observability:** Establish distributed tracing, centralized logging, and proactive monitoring using Application Insights and APM tools to guarantee 99.99% uptime.
- **Mentorship & Capacity Building:** Mentor senior developers, foster a culture of engineering excellence, and lead technical evaluation in hiring.

---

## 📋 Required Qualifications

- **10+ years** of backend engineering experience with deep mastery of **C#, .NET Core / .NET 8**, and distributed system patterns.
- Proven experience building **high-scale, low-latency RESTful APIs and microservices**.
- Deep knowledge of **Asynchronous Processing and Message Brokers** (Azure Service Bus, RabbitMQ, Kafka, or AWS SQS/SNS).
- Expert-level database proficiency in **SQL Server, PostgreSQL, or NoSQL engines (MongoDB / DocumentDB)** with proven track record of query tuning under heavy concurrency.
- Strong hands-on experience with **Containerization and Cloud Orchestration** (Docker, Kubernetes).
- Demonstrated experience in **Domain-Driven Design (DDD), Event Sourcing, CQRS**, and Clean Architecture.
- Proven track record of reducing latency, eliminating system bottlenecks, and optimizing cloud infrastructure costs.
