# Lead .NET & Cloud Solutions Architect

**Company:** HealthBridge Cloud Technologies  
**Location:** Remote (EST / North America Timezones)  
**Employment Type:** Full-Time  
**Experience Level:** Lead / Principal (8–10+ years)  
**Industry:** Healthcare SaaS / Enterprise Cloud Infrastructure  

---

## 🏢 About the Role

HealthBridge is seeking an experienced **Lead .NET & Cloud Solutions Architect** to spearhead the modernization of our enterprise healthcare platforms into next-generation, multi-tenant cloud SaaS systems. In this role, you will provide technical leadership across distributed engineering squads, establish architectural standards, design microservices on Microsoft Azure, and guide the migration of legacy systems to high-availability cloud-native architectures.

---

## 🎯 Key Responsibilities

- **Architecture & System Design:** Architect resilient, secure, and multi-tenant cloud microservices using C#, .NET 8 / ASP.NET Core, and Microsoft Azure.
- **Legacy Modernization:** Lead the architectural decoupling of monolithic/desktop systems into event-driven cloud services utilizing the Strangler Fig pattern.
- **Technical Leadership:** Lead a cross-functional squad of 6–10 software engineers and QA professionals, conducting code reviews and setting engineering standards.
- **Cloud & DevOps Governance:** Drive containerization strategy with Docker and Kubernetes (AKS), while designing automated CI/CD pipelines for zero-downtime releases.
- **Messaging & Event Streaming:** Design decoupled asynchronous communication workflows using Azure Service Bus (Queues & Topics) and Azure Functions.
- **Stakeholder Collaboration:** Partner directly with VP of Engineering, Product Owners, and healthcare enterprise clients to define roadmaps and technical milestones.
- **Security & Compliance:** Ensure software architecture strictly complies with HIPAA, SOC 2, and data residency regulations.
